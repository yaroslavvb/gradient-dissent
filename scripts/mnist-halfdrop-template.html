Each subset trains a separate network from the same seed-matched initialization and data order. Learning rate 0.01, batch 64, 100 epochs. The feature layer and classifier always remain. These exploratory results use a previously studied MNIST test set.

What makes 50% training dropout possible here? Each middle layer has a bypass carrying the first output-width features around its learned transform. A dropped branch uses that bypass; a retained branch adds twice its learned output during training. At testing it adds its learned output once. Thus every model has a usable path through a missing branch. This is a residual adaptation of the Ciresan-width MLP.
