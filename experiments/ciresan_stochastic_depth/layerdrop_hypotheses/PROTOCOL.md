# Fable hypotheses: exact-mask MNIST checkpoint audit

Status: pre-evaluation protocol, 2026-09-09. No new neural training is required or authorized by this document. Freeze this file and the audit implementation/specification hashes before computing new mask outcomes. The root task controls all paid dispatches and the existing ledger. This protocol tests operational consequences of the supplied Fable argument; it does not assume that its theoretical assertions are correct.

## Scope, evidence and irreversible boundaries

Reuse the completed normalized-input, linear-output main-cohort checkpoints for `residual`, `sd_constant` and `sd_annealed`, seeds 101–103: nine trained models, with both `best.pt` and `final.pt`, giving 18 checkpoint states. The validation-selected checkpoint is primary; the final epoch is secondary. Do not select the better endpoint after seeing deletion results. Also audit residual+unit-dropout at both endpoints (six states, secondary regularization control), and plain MLP checkpoints at both endpoints (six states), for **30 checkpoint states total**. Enumerate all 16 interventions for plain too, but label them **forced crop surgery on a plain MLP**: its kept transition remains the original affine/ReLU without residual addition, and its deleted transition is replaced by a crop/ReLU it was never trained to use. This is a diagnostic of disruptive surgery, not equivalent trained bypasses or an architecture-only causal comparison. Central inferential claims remain the 18 residual-dense/SD states. Historical raw/ReLU fidelity checkpoints are outside this audit.

The official test set and seeds 101–103 were already used in prior investigations. The original 10,000-example validation set also selected learning rates and checkpoints. A new split cannot erase that reuse. Therefore all findings are exploratory, conditional on these checkpoints and data; “held out” below means withheld from the new router-fitting/calibration procedure, not globally unseen or suitable for an independent generalization guarantee.

Never change model parameters, checkpoint choice, original dataset/split, residual architecture, or the original trainer. Record checkpoint SHA-256, executed model/audit source hashes, input dataset/index hashes, device and software metadata. For every checkpoint, verify that the all-kept audit forward agrees with the original dense evaluation: compare logits directly on a deterministic small probe, and compare full validation/test loss, accuracy and error indices with the recorded run. Use a documented numerical tolerance for logits/CE, not a waiver of prediction differences. Unexpected mismatches stop that checkpoint's analysis; retain the failure.

`CiresanMLP.eval()` ignores `active` masks. Implement a separate deterministic audit forward: eval semantics, no unit dropout, explicit branch presence, surviving branches at scale **one**. Do not accidentally sample gates or apply training-time inverse-survival scaling. This is functional deletion at inference. Although all 16 masks had nonzero probability during portions of SD training, their unscaled conditional networks are not identical to the inversely scaled training subnetworks.

## Exact masks, costs and splits

Let mask bit j indicate presence of eligible branch j, in shallow-to-deep order, j=0,1,2,3. Integer 0 keeps none and integer 15 keeps all. Enumerate every integer 0–15 once; record the explicit bit vector with every output. The stem and final classifier remain compulsory. A skipped block still crops the previous activation and applies ReLU. For plain surgery a kept block remains its original affine/ReLU; do not add a shortcut to kept plain blocks. Keeping only a prefix of branches is a **prefix-mask intervention with the same final classifier**, not a separately trained early-exit head. The all-skipped model retains a learned stem, repeated crops and the learned classifier; it is neither “no computation” nor a bigram model.

Nominal affine MACs per example are

`C(mask) = 1,965,000 + 5,000,000*b0 + 3,000,000*b1 + 1,500,000*b2 + 500,000*b3`.

The constant term includes stem 784×2500 and classifier 500×10. Full cost is 11,965,000. Bias, activation, routing, indexing and memory costs are not in this MAC count. Equal numbers of retained branches do not imply equal work. Report individual masks, retained-branch strata and the MAC/quality frontier. Do not label a MAC reduction as measured latency or energy savings.

Partition the existing validation positions with a CPU `torch.randperm(10000, generator=torch.Generator().manual_seed(20260910))`: first 5,000 positions are **policy-fit**, last 5,000 **calibration**. Save explicit positions and their hashes before evaluation. Use these same positions for every checkpoint; no stratification or reshuffle after observing outcomes. Official test remains all 10,000 examples, scored once under frozen reporting/policy choices. Exact-mask test logits can be computed in the audit jobs but must remain withheld from policy fitting and selection until the policy manifest is written and hashed.

A mechanistic probe is the first **128 policy-fit positions** in that same permutation order. It is fixed independent of accuracy, digit, margin, mask resilience or gradient. Use every selected example, including full-model mistakes; also report separately the full-correct subset where relevant. Probe mechanisms on both endpoints, with selected checkpoint analyses primary. Its small size limits precision; do not enlarge or cherry-pick the probe after seeing a result. Mechanistic prediction comparisons use fixed analytic predictors/correlations, not a regression fitted and evaluated on the same probe.

The branch-gain/Jacobian mechanism analyses target the 18 residual/SD states, with unit-dropout states secondary if included. Plain forced-crop surgery always contributes its binary-mask spectrum and outcomes, but no continuous residual-gain probe is required for it: adding `crop + alpha*affine` to a plain block would fail the all-kept parity requirement. If a plain continuous diagnostic is included, its separately labeled definition must interpolate `ReLU((1−alpha)*crop + alpha*affine)` so alpha=0/1 agree with its surgery/full endpoints; it has no survival-rescaling training interpretation.

## Test 1 — Does SD buy functional redundancy, and for which examples?

Hypothesis: relative to residual-dense training, SD reduces damage from deleting branches, rather than merely changing the dense model's original mistakes. The primary mask panel is the **six masks retaining exactly two of the four eligible branches**, uniformly weighted. It tests a fixed deletion severity without giving extra weight to the single all-skipped endpoint. All 16 individual masks, all four nonfull retained-count strata and uniformly weighted 15 nonfull masks are secondary descriptive outputs; never make the primary panel depend on its outcome.

For every example i and mask m record CE, predicted digit, correctness, and the full-model true-class logit margin. Define excess CE `D_i(m)=CE_i(m)−CE_i(15)`, without clipping negatives, and harmful flip `F_i(m)=1[full correct and mask wrong]`. Also record beneficial flips `[full wrong and mask correct]` and agreement with the full prediction. Primary model statistics are mean excess CE and the unconditional harmful-flip rate over the six masks; report conditional failure among full-correct examples too, with its denominator. Record absolute masked CE/accuracy alongside excess quantities, so a low-quality or insensitive full model cannot win solely by changing little.

Example resilience is the fraction of those six masks that preserve a full-correct prediction; report its distribution, not only an average. For each digit report all example counts, dense accuracy, masked accuracy, harmful and beneficial flips, and mean excess CE. Report the actual failing masks for representative examples selected by a frozen rule: lowest original MNIST index within each predeclared category (always preserved, mixed, always lost), up to two per digit. These are illustrations, not a selected performance sample.

Compare each SD recipe to residual dense using same-seed differences at each endpoint. Three seed-paired 95% Student-t intervals use df=2 and t=4.302653; examples and masks are repeated within a seed and are not 60 or 180 independent model replicates. Primary directional support requires a negative excess-CE contrast; a harmful-flip contrast and absolute quality contextualize it. A nonnegative contrast or an interval spanning zero does not support the directional claim at that precision. A failure here falsifies the operational redundancy hypothesis for these checkpoints/panel, not all residual networks.

## Test 2 — Are apparent “easy digits” just high-margin examples?

Hypothesis: **digit 1 is more deletion-resilient than digits 4 and 9**, including after adjustment for full-model confidence. The primary class contrast is resilience(1) minus the mean of resilience(4) and resilience(9), using the six two-retained masks and full-correct examples. Report 1−4 and 1−9 separately as well. The complete ten-digit ranking is exploratory. Full-model confidence is a confounder: a digit may survive deletion simply because its original decision lies farther from a boundary. True class and full-model margin are analysis covariates; they are forbidden as cost-free inputs to the deployable routing policy.

Use the unscaled true-class logit margin `z_y−max(z_other)` and analyze full-correct examples primarily. Derive ten margin-bin edges from full-correct policy-fit examples separately for each checkpoint; use the same edges for all digits of that checkpoint. Ties collapse duplicate edges rather than inventing artificial bins. Before test unblinding, use calibration counts to freeze common-support bins with at least 20 full-correct examples of each of digits 1, 4 and 9 for the primary contrast; use a separately reported all-ten-digit common-support set for the exploratory full ranking. If no common support exists, report the failure of this adjustment rather than widening bins or dropping inconvenient digits post hoc. Fixed weights are the calibration full-correct mass across those supported bins, normalized to sum one.

Report raw and margin-standardized per-digit harmful-flip/resilience rates, retained sample fractions and every bin count. If a frozen test digit/bin is empty, its standardized estimate is undefined; do not silently change weights. As an additional description, report within-bin distributions and class rank changes. For an exploratory conditional-association test, use 1,000 permutations (seed 20260913) of digit labels **within margin bins**, keeping each example's six-mask aggregate together, and compare the observed between-digit variance with its permutation reference. State the exchangeability assumption and that coarse binning leaves residual confounding. Do not interpret this as a causal property of digit identity.

The “intrinsically more resilient digit” story is weakened if the raw class ranking disappears/reverses after adjustment or fails to replicate across the three seeds. Stable adjusted differences across seeds support a class-associated pattern, but not a mechanism. Display both raw and adjusted results even when adjustment removes the attractive story. The claim about digit 1 versus 4/9 is frozen here before new ablation outcomes; other digit rankings are exploratory. Report the class contrast over the three seeds with its paired-seed interval, raw and adjusted. A nonpositive adjusted contrast contradicts this operational ordering on common support; limited coverage weakens generalization beyond that support.

## Test 3 — Direction matters more than increment size

Hypothesis: deletion damage depends on the downstream-sensitive direction of the removed contribution, not just its angle/norm. The tapered crop/ReLU architecture has changing dimension and is not an equal-dimensional near-identity flow. Do not compare unequal-length vectors or assert that the residual form prevents coordinate changes.

At the full-network state for each eligible block, let `h` be its post-ReLU output and `p` the same-width cropped bypass output, with its ReLU. Let `delta=p−h`. This is the actual local state replacement caused by deleting that block while its upstream computation remains full. Record `||delta||/max(||h||,1e−12)`, angle between h and p, and any zero-vector cases explicitly. The affine branch output before ReLU is not generally delta.

On the fixed 128-example probe, compute the downstream CE gradient with respect to each full block output and the per-example first-order prediction `gradient·delta`. Compare it to actual single-block-deletion excess CE: signed error, MAE, rank correlation, and R² against a zero-change baseline. Use downstream recomputation with upstream states fixed; do not differentiate through a newly recomputed delta. Compare the rank correlations of increment norm and angle with damage as fixed proxies, rather than fitting a norm predictor to the same probe.

Also compare directional logit sensitivity along delta against one Gaussian direction per example/block, generated with seed 20260911 and normalized to the same norm. Estimate logit directional response by centered finite differences at epsilon 0.001 and 0.01, with absolute response and the two-epsilon disagreement reported. If an exact JVP implementation is available and already qualified, it can replace the estimate; pin that choice before execution. Full deletion remains the nonlinear endpoint. A small local derivative does not certify robustness to a unit-size deletion, and a direction norm does not bound the full Jacobian's spectral norm or prove contraction.

The directional hypothesis is supported only if directional-gradient predictions track actual damage better than increment-size/angle proxies on the held probe and behave consistently across seeds. Poor R², wrong signs or large interpolation/finite-difference disagreement are useful falsifications of local linear reasoning. An advantage specific to the deletion direction over random directions supports anisotropy; it does not identify a complete read/write circuit or a global Lipschitz bound.

## Test 4 — Exact interactions and a direct interpolation challenge

Hypothesis: SD makes the mask response more nearly additive/low-interaction. Evaluate it separately for centered logits and CE; the softmax/cross-entropy nonlinearity can create loss interactions even when logits are affine. Do not call a loss-spectrum coefficient a literal count of computational paths.

All 16 masks allow an exact Walsh expansion on the four binary presence variables and an exact Möbius expansion anchored at the all-skipped mask; there is no mask-sampling approximation here. Define Walsh coefficients using x_j=2*b_j−1 and the uniform factor 1/16. Subtract each example/mask's mean across classes before the logit expansion to remove a common-logit shift. Report coefficient energy for degrees 0–4 and the fraction of nonconstant energy at degrees ≥2, with zero/near-zero denominators flagged. Report unnormalized energies as well; normalized fractions alone can make an almost constant failed model appear favorable. For loss, retain signed effects and the absolute base/full loss as well as squared-energy summaries.

The primary interaction contrast is the selected-checkpoint SD-minus-dense change in per-example higher-order **centered-logit** energy fraction, averaged over the full test set and paired over seeds. CE interaction fractions and final checkpoints are secondary. Additionally report each double-deletion interaction around the full mask: `L(full−i−j)−L(full−i)−L(full−j)+L(full)`. Small average signed interactions can conceal cancellation, so include RMS/absolute magnitudes and per-example distributions.

Every function on four binary variables has an exact multilinear extension of its corner values; exact corner reconstruction is a numerical check, not evidence that the real network interpolates linearly. On the fixed 128-example mechanistic probe, actually evaluate branch gains a=0,0.25,0.5,0.75,1 for each single branch with all others at one, and the all-four-gains=a diagonal. Reuse binary endpoints from the exact-mask table. For each SD checkpoint also evaluate each branch at gain 1/rho_j, with others at one, where rho_j is its survival probability in the checkpoint epoch: constant pmax=0.4; decreasing pmax=0.8*(1−(epoch−1)/99), multiplied by (j+1)/4. The final decreasing checkpoint has rho=1, so this adds no new point. Compare the dense gain-one prediction with rho*F(1/rho)+(1−rho)*F(0), separately for centered logits and CE. This directly tests the training-endpoint interpolation argument without conflating averaging logits, losses and predictions. Compare the resulting centered logits and CE against both the corner multilinear interpolant and its degree-1 truncation. These intermediate gains are withheld evaluation points, not used to estimate the corner coefficients. Keep biases scaled with their branch affine contribution, and apply ReLU afterward.

A nondecreasing interaction fraction, large intermediate-gain error, or robust masks despite large interactions weakens the corresponding low-order/“works iff near-linear” claim. Neither low interaction nor a short apparent path spectrum proves that skip tolerance arises from interchangeable ODE steps. This architecture cannot test layer-reordering invariance across unequal widths without a new intervention.

## Test 5 — Can a cheap, label-free router exploit the resilience?

Hypothesis: cheap input-dependent mask choice improves the accuracy-versus-compute frontier over a validation-selected static mask. No new neural model training is planned. Use **7×7 average-pooled raw-image features**: average each disjoint 4×4 patch of the 28×28 image, divide by 255 and flatten to 49 features. These features require no learned stem, full-model evaluation or true label. True digit, test labels, full-model prediction/margin and all-mask predictions are forbidden at deployment.

Fit one multioutput `DecisionTreeRegressor(max_depth=3, min_samples_leaf=200, random_state=20260909)` per checkpoint, using the 5,000 policy-fit examples. Record the exact scikit-learn version. Its 16 targets are per-example `1[mask wrong]−1[full wrong]`, including beneficial flips; dense target/predicted extra error is fixed to zero. This tree predicts per-mask error changes, not labels. All neural parameters remain frozen. For each lambda in **{0,0.001,0.002,0.005,0.01,0.02,0.05,0.1,0.2,0.5,1}**, choose each example's mask minimizing predicted extra error plus `lambda*C(mask)/C(full)`. Score ties use **higher MACs, then higher mask integer**, favoring the full model when predicted extra errors tie at lambda=0. Save the fitted tree, feature definition, index hashes and action/tie rules before calibration.

Use the remaining 5,000 calibration examples only to select lambda. The primary feasibility rule is observed net extra error at most **0.002**, equivalent to 10 additional errors among 5,000 calibration examples. Among feasible candidates choose maximum mean MAC saving, then higher calibration accuracy, then smaller lambda. Always include the all-full fallback, so failure to find a useful policy is a valid result. Save and hash the selected policy before test unblinding. The rule is an empirical point-estimate tolerance, **not a confidence-certified population guarantee**. Beneficial flips can compensate harmful flips in net error; report both, as well as CE, class-wise failures and the entire calibration candidate table. Do not impose a new CE selection constraint after seeing results.

Independently choose the cheapest static mask satisfying the same calibration extra-error tolerance; ties use higher calibration accuracy and then **higher mask integer**. The random comparator uses the selected router's test mask multiset shuffled among test examples with a fixed seeded permutation (`20260912`), yielding exactly the same realized nominal MAC distribution while removing input-dependent assignment. This uses router predictions and no test labels; its algorithm is frozen before test access. Retain one permutation per checkpoint, its seed/hash, and qualify that one random realization does not capture all random-policy uncertainty. Full inference is always another comparator.

Evaluate the frozen dynamic/static/random/full policies once on all official test examples. Report accuracy, CE, net/harmful/beneficial error changes, class-wise errors, mask frequencies and mean MACs. A per-example oracle using true labels and all-mask predictions may be shown only as an unattainable bound; it is not a deployable result. Central policy claims concern the residual-dense/constant-SD/decreasing-SD checkpoints. Unit dropout is secondary and plain forced-surgery routing is a separately labeled diagnostic.

Support requires better held-out quality at comparable nominal work, or lower work while preserving the frozen tolerance, relative to static/random baselines; test tolerance failures or no advantage are reported directly. Costs of static and dynamic candidates can differ, so show all quality/cost points and avoid declaring a matched-cost win from unmatched points. Do not refit the router on all validation data after calibration. This would change the selected model without a fresh check.

A fourth bounded job measures actual end-to-end resident-input inference for the **nine primary validation-selected residual/SD checkpoints**. Include pooling/features, tree routing, grouping/gathering, all affine calls and scattering outputs back to original order. Compare full inference and the frozen router, with static masks as feasible context, on the same GPU/batch size; record source/GPU/runtime and confirm predictions agree with the cached functional evaluation. The fixed timing specification is **batch 2048**, **two warmup batches per method** and **three synchronized whole-test passes** per method, with method order rotated each pass; record the first whole-pass timing and the median across passes. Model loading, tree fitting and checkpoint transfer are reported separately, not hidden in an inference claim. Any implementation using CPU routing/transfers must include those in the measured inference interval. No masked-work estimate or cached-logit simulation is labeled measured latency or energy.
